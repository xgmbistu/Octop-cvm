# Project rules

This directory holds project rules that Implement must follow. Initialization creates only this note. Put coding, test, API, security, and compatibility constraints in other Markdown files beside it.

## How they apply

- Task creation snapshots this directory to that task's `_rules/rules/`. Implement follows the snapshot.
- This note is not a coding standard. When it is the only file, record that there are no extra project rules. Core gates still apply.
- If a rule conflicts with a Core gate, the stricter requirement applies. Stop and ask when the conflict cannot be resolved; do not relax either side on your own.
